# Smartphone Analytics Dashboard

## First Batch | Power BI Mini Project Reference #03

---

## Project Overview

The **Smartphone Analytics Dashboard** is a trainer-created Power BI reference project developed as part of the **First Batch Power BI Master Class & Internship** conducted by **Infinity Code Nexus**.

The dashboard demonstrates how smartphone-related business data can be transformed into an interactive analytical report using Power BI.

The project focuses on sales, pricing, brand comparison, ratings, and price-category analysis.

> **Note:** This is a **Trainer-Created Reference Dashboard** and is not a participant submission.

---

## Dashboard Objective

The objective of this dashboard is to analyze smartphone-related data through:

- Sales Analysis
- Brand-wise Sales
- Price Analysis
- Brand-wise Price Comparison
- Rating Analysis
- Price Category Analysis
- Budget vs Premium Analysis
- Detailed Brand-level Data
- Interactive Brand Filtering

## Brand-wise Sales Analysis

The dashboard compares sales across the available smartphone brands.

The visualization allows users to understand how sales values differ between brands.

This demonstrates the use of comparative visualizations for business analysis.

---

## Price Analysis

The dashboard provides a comparison of smartphone pricing across brands.

This helps users explore differences in pricing and understand how price-related metrics can be represented through Power BI.

---

## Price Category Analysis

The dashboard categorizes smartphones based on pricing segments.

The displayed categories include:

- Budget
- Premium

A donut-style visualization is used to provide a quick comparison of the price categories.

---

## Brand-level Data Analysis

The dashboard contains a detailed table providing brand-level information.

The table includes analytical fields such as:

- Brand
- Sum of Price
- Sum of Sales
- Sum of Rating
- Average Price
- Price Category

This demonstrates how detailed tabular analysis can complement visual analytics.

---

## Rating Analysis

The dashboard includes rating-related analysis to provide an additional perspective on smartphone data.

Rating information can be compared alongside sales and pricing metrics to demonstrate how multiple business attributes can be presented within one analytical report.

---

## Interactive Brand Filtering

A **Brand slicer** is included to allow users to interact with the dashboard.

Users can select the available brand and analyze the corresponding information across the report.
