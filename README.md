## About This Repository

Welcome to the **Power BI First Batch Mini Project Reference Series** by **Infinity Code Nexus**.

This repository contains a collection of **trainer-created Power BI reference dashboards** developed as part of the **First Batch Power BI Master Class & Internship**.

The purpose of this repository is to demonstrate how different business and analytical domains can be transformed into structured, interactive, and visually meaningful Power BI dashboards.

These dashboards were created as **reference projects for learners** to understand how a Power BI mini project can be planned, designed, analyzed, and presented.

> **Important:** The dashboards in this repository are **Trainer-Created Reference Projects** and are **not participant submissions**.
