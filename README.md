# IPL Analytics Dashboard

## First Batch | Mini Project Reference #01

This dashboard was created as a **trainer-created reference example** during the First Batch Power BI Master Class & Internship.

The purpose was to demonstrate how a Power BI mini project can be structured using KPIs, filters, charts, comparisons, and interactive analysis.

## Dashboard Components

- Total Runs
- Average Wickets
- Total Matches
- Runs by Team
- Wickets by Team
- Match Status
- Team-wise Filtering
- Interactive Analysis

## Learning Focus

This dashboard demonstrates the basic structure of a sports analytics report in Power BI.

### Structure

**KPIs → Filters → Visualizations → Comparisons → Analysis**

## Training Objective

The dashboard was created to help participants visualize the expected structure of their own Power BI mini projects.

**Learn → Practice → Build → Analyze**
