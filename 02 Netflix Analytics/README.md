# Netflix Analytics Dashboard

## First Batch | Power BI Mini Project Reference #02

---

## Project Overview

The **Netflix Analytics Dashboard** is a trainer-created Power BI reference project developed as part of the **First Batch Power BI Master Class & Internship** conducted by **Infinity Code Nexus**.

The dashboard demonstrates how content-related data can be transformed into an interactive analytical report using Power BI.

This project was created as a practical reference for learners to understand dashboard structure, KPI development, visual analysis, filtering, and presentation.

> **Note:** This is a **Trainer-Created Reference Dashboard** and is not a participant submission.

---

## Dashboard Objective

The objective of this dashboard is to provide an analytical view of movie-related data through:

- Movie Count Analysis
- Average Rating Analysis
- Release Count
- Genre Analysis
- Movie Rating Categories
- Year-wise Movie Trends
- Average Rating by Genre
- Detailed Movie-level Analysis
- Interactive Genre Filtering

---

The dashboard provides a comparison of movies across major genres.

The dashboard includes a year-wise movie release analysis.

The displayed trend includes:

| Year | Movie Count |
|---|---:|
| 2023 | 365 |
| 2024 | 307 |

This helps demonstrate how time-based analysis can be presented through Power BI visualizations.

## Rating Analysis

The dashboard categorizes movies based on rating levels.

The displayed categories include:

- Average
- Top Rated

The rating distribution is presented through a visual comparison to provide a quick understanding of the analyzed movie ratings.

---

## Average Rating by Genre

The dashboard provides an average-rating comparison across:

- Action
- Comedy
- Drama

This allows users to compare rating performance between different movie genres.

## Detailed Movie Analysis

A detailed table is included in the dashboard to provide movie-level information.

This demonstrates how a Power BI report can combine:

- Summary KPIs
- Visual analysis

- Trend analysis
- Detailed records

within a single report.
