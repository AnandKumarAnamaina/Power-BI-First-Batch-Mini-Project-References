# Smartphone Analytics Dashboard

## First Batch | Power BI Mini Project Reference #03

---

## Project Overview

The **Smartphone Analytics Dashboard** is a trainer-created Power BI reference project developed as part of the **First Batch Power BI Master Class & Internship** conducted by **Infinity Code Nexus**.

The purpose of this dashboard is to demonstrate how smartphone-related business data can be transformed into an interactive analytical report using Power BI.

This dashboard is designed as a **reference project for learners** to understand how KPIs, charts, tables, categories, filters, and comparative analysis can be combined into a structured Power BI dashboard.

> **Note:** This is a **Trainer-Created Reference Dashboard** and is not a participant submission.

---

## Dashboard Objective

The primary objective of this dashboard is to demonstrate analysis of:

- Smartphone Sales
- Smartphone Pricing
- Brand Performance
- Product Ratings
- Price Categories
- Brand-wise Comparisons
- Interactive Brand Filtering

The dashboard provides a compact view of key business metrics while allowing users to explore the data through visual analysis and filtering.

## Dashboard Analysis

### 1. Sales by Brand

The dashboard compares smartphone sales across brands using a horizontal bar chart.

The displayed analysis includes:

- Apple
- Xiaomi

The visualization allows users to compare the sales contribution of the available brands.

---

### 2. Price by Brand

A comparative column chart is used to analyze the price associated with each brand.

This helps demonstrate how Power BI can be used to compare pricing metrics across different brands.

---

### 3. Brand by Price Category

A donut chart presents the distribution of smartphones across price categories.

The dashboard includes categories such as:

- Budget
- Premium

This visualization provides a quick overview of the distribution between different price segments.

---

### 4. Brand-Level Data Table

A detailed table provides a summarized view of:

- Brand
- Sum of Price
- Sum of Sales
- Sum of Rating
- Average Price
- First Price Category

This section demonstrates how tabular data can complement graphical visualizations within a Power BI report.

---

### 5. Price Trend by Brand

The dashboard includes a visual comparison of price values across brands.

This provides an additional perspective for understanding differences in pricing between the analyzed brands.

---

### 6. Interactive Brand Filter

A **Brand slicer** is provided to allow users to interact with the dashboard.

Users can select available brands and analyze the corresponding dashboard information.
